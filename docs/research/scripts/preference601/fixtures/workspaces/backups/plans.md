# Two backup plans for the studio file server

Both plans are invented offers from Coldharbour Storage.

## Plan A
- Incremental backup every night at 01:00
- Full backup every Sunday
- Copies kept for 30 days
- Offsite copy in one region
- 18 EUR a month for up to 2 TB

## Plan B
- Incremental backup every 4 hours
- Full backup on the 1st and the 15th of each month
- Copies kept for 90 days
- Offsite copies in two regions
- 31 EUR a month for up to 2 TB
- Restores of a single file take up to 6 hours to start
